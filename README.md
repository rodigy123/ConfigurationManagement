# Визуализатор графа зависимостей (Alpine Linux, apk)

CLI-инструмент: зависимости пакета Alpine Linux -> граф -> PNG (PlantUML).
Менеджеры пакетов и сторонние библиотеки для получения зависимостей
не используются, только стандартная библиотека Python 3.11+.

## Конфигурация (config.toml)
- `package_name` - имя пакета (в режиме test: большие латинские буквы)
- `repository_url` - URL репозитория или путь к файлу тестового графа
- `repository_mode` - `remote` или `test`
- `package_version` - версия пакета, например `1.24.0-r7`
- `output_image` - имя PNG-файла с графом

## Запуск и тесты
```
python src/main.py config.toml
pip install -r requirements.txt && pytest tests/
```

## Этапы
1. Чтение TOML, проверка всех параметров.
2. Скачивание `<repository_url>/<имя>-<версия>.apk`, чтение `.PKGINFO`.
3. Граф с транзитивными зависимостями (рекурсивный DFS), поиск циклов.
   Режим `test`: `repository_url` - файл с описанием графа, строки
   `A: B C` (пакеты - большие латинские буквы). Примеры: `test_repo*.txt`.
4. Порядок загрузки (режим `--order`) - только в коммите этапа 4.
5. Описание графа на PlantUML (`.puml`) и изображение `.png`
   (локальный `plantuml`, если установлен, иначе сервер plantuml.com).

`APKINDEX.tar.gz` используется только для сопоставления имён: так
находятся версия `.apk` зависимости и пакет, предоставляющий `so:...`.

## Сравнение с apk (этап 5)
Сравнивать с `apk dot nginx` (Graphviz) в контейнере `alpine:3.18`.
Расхождения возможны: apk-граф содержит версии, `so:`-вершины и учитывает
уже установленные пакеты; здесь вершины - пакеты, `so:` разрешены в пакеты,
а `/bin/sh` и `!конфликты` пропущены.
