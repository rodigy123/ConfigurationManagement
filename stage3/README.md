# Эмулятор Shell (Вариант 21)

Консольный эмулятор командной строки UNIX-подобной ОС.

## Этап 1
Реализован базовый REPL, парсер переменных окружения, обработка ошибок и заглушки команд.

## Этап 2
Добавлены параметры командной строки (--vfs, --script), отладочный вывод и режим выполнения стартового скрипта.

## Этап 3
Реализована виртуальная файловая система (VFS) в памяти.
Добавлена команда `vfs-save` для сохранения на диск.

## Запуск
```bash
python src/emulator.py --vfs ../vfs_deep --script startup.txt
